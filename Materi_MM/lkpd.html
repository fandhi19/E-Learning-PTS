Aktivitas 1: Pemetaan Komponen Mail Merge (Konsep Bab I)

Bobot: 25 Poin
Skenario Kasus:

Panitia kegiatan sekolah ingin mencetak 360 Sertifikat Penghargaan untuk seluruh pemenang lomba antarkelas. Di dalam sertifikat tersebut terdapat 6 elemen informasi berikut:

  1. Logo Sekolah dan Judul "SERTIFIKAT PENGHARGAAN"
  2. Nama Lengkap Siswa Pemenang
  3. Kelas Asal Siswa
  4. Kalimat pengantar tetap: "Diberikan kepada siswa tersebut atas prestasinya sebagai:"
  5. Predikat Juara & Cabang Lomba (contoh: Juara 1 Basket Putra)
  6. Jabatan, Tanda Tangan & Nama Kepala Sekolah
Tugas 1A: Kelompokkan ke-6 nomor elemen di atas ke dalam tabel arsitektur Mail Merge berikut!
Komponen Pilar Aplikasi Nomor Elemen (1–6) Alasan Pengelompokan (Sifat Data)
Main Document
(Dokumen Master) 		Microsoft Word
Data Source
(Sumber Basis Data) 		Microsoft Excel

Aktivitas 3: Logika Aturan Rules & Format Switch Code (Konsep Bab III)

Bobot: 25 Poin
Kasus 3A — Aturan Logika Percabangan (If... Then... Else...):

Dalam piagam kejuaraan olahraga, panitia ingin naskah secara dinamis menampilkan kalimat "Juara Pertama" jika kolom Skor lebih dari atau sama dengan 90 (≥ 90), dan menampilkan "Peserta Berprestasi" jika skor di bawah 90 (< 90). Lengkapilah parameter kotak dialog Rules pada tabel berikut!

Parameter Menu Rules (If... Then... Else...) Isian Konfigurasi yang Tepat
Field name (Nama kolom yang diuji)
Comparison (Operator pembanding)
Compare to (Nilai batas pembanding)
Insert this text (Teks jika kondisi terpenuhi)
Otherwise insert this text (Teks jika tidak terpenuhi)
Kasus 3B — Modifikasi Format Switch Codes (Alt + F9):

Setelah menekan pintasan Alt + F9 di Word, tuliskan kode modifikasi lengkap menggunakan Switch Code tanggal (@) dan angka rupiah (#) sesuai panduan Bab III Halaman 9!

No Gejala / Masalah Teknis di Lapangan Penyebab Utama Langkah Solusi Perbaikan
1 Muncul pesan peringatan "Database Is Locked" saat menautkan file Excel lewat Select Recipients.
