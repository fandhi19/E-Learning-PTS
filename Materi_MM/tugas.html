Kumpulkan Berkas Praktik Mail Merge

Unggah file hasil integrasi dokumen Microsoft Word (.docx), berkas sumber data Microsoft Excel (.xlsx), serta berkas hasil cetak gabung PDF (.pdf) langsung ke Google Drive guru pengampu.

Format File Didukung:
Word (.docx) Excel (.xlsx) Ekspor PDF Arsip (.zip)

1. Identitas Peserta Didik & Proyek

Pastikan data nama, kelas, dan presensi sesuai dengan presensi sekolah.

2. Unggah Berkas Praktik Mail Merge

Pilih salah satu metode pengumpulan berkas yang paling mudah bagi Anda.

Maks. 25 MB per Berkas

Silakan unggah minimal 1 file berkas utama (Dokumen Word, Data Excel, PDF Ekspor, atau Arsip ZIP gabungan):

1. Dokumen Word Master

Format: .docx atau .doc

Pilih Berkas Word

2. Sumber Data Excel

Format: .xlsx, .xls, .csv

Pilih Berkas Excel

3. Hasil Cetak PDF

Format: .pdf (Finish & Merge)

Pilih Berkas PDF
Punya Berkas Gabungan (.ZIP / .RAR)? Anda juga dapat mengemas seluruh berkas Word + Excel + PDF dalam 1 arsip zip.

Petunjuk Tautan Google Drive / Cloud:

Pastikan akses berbagi tautan diatur ke "Siapa saja yang memiliki link dapat melihat" (Anyone with the link can view) agar guru dapat membuka dan memeriksa berkas Anda.

Checklist Verifikasi Kerapian Berkas Sebelum Dikirim:
  • Tabel Excel telah memenuhi 4 Aturan Emas: Header di Baris 1, tanpa spasi kosong, dan tanpa Merged Cell.
  • Nama penanda field pada naskah Word telah terhubung sempurna dan diuji lewat tombol Preview Results.
  • Data uji coba berisi minimal 10 penerima yang valid dan berbeda.
