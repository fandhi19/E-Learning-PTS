BAB I Quest 01 • Alokasi 25 Menit

Komponen Dasar & Pengertian Sistem Operasi

Hardware, Software, dan Jembatan Penghubungnya. Membedakan wujud fisik dan instruksi digital, memahami pengertian SO, serta mengurutkan tahapan proses komputer dibangunkan (Booting).

1. Hardware (Perangkat Keras) dan Contohnya

Seluruh komponen fisik yang tampak nyata (bisa dilihat & disentuh langsung) dalam alur IPO-S

A. Perangkat Input (Masukan)

Memasukkan data atau perintah ke komputer.

Contoh: Keyboard, Mouse, Joystick, Microphone, Webcam, Scanner, Sensor.
B. Perangkat Proses (Pengolah)

Otak utama yang mengolah instruksi & komputasi data.

Contoh: CPU (Prosesor), RAM (Memori Sementara), GPU / VGA Card.
C. Perangkat Output (Keluaran)

Menampilkan hasil pengolahan data ke pengguna.

Contoh: Monitor (Terminals), Speaker, Proyektor, Printer.
D. Penyimpanan (Storage)

Menyimpan file & program secara permanen (non-volatile).

Contoh: SSD (Solid State Drive), Harddisk (HDD), Flashdisk, Disks.

2. Software (Perangkat Lunak) dan Contohnya

Kumpulan instruksi atau program digital tak kasat mata yang mengatur kerja hardware

Kategori 1 Untuk Pengguna
A. Software Aplikasi (Application Software)

Program yang dirancang khusus untuk menyelesaikan tugas spesifik pengguna sehari-hari, seperti mengetik, menghitung, mendesain, atau hiburan.

Contoh Populer: Microsoft Word, Excel, PowerPoint, Canva, Google Chrome, WhatsApp, Spotify, Game.
Kategori 2 Fondasi Sistem
B. Software Sistem (System Software)

Program utama yang bertugas mengelola seluruh hardware, mengalokasikan sumber daya komputer, dan menjadi wadah tempat berjalannya software aplikasi.

Contoh Utama: Sistem Operasi (Windows 11, Linux Ubuntu, Android 15, macOS Sequoia).

3. Pengertian Sistem Operasi & Tahapan Booting

Bagaimana Sistem Operasi didefinisikan dan bagaimana ia dibangunkan pertama kali saat komputer dinyalakan

Definisi Resmi

Sistem Operasi (Operating System / OS) adalah perangkat lunak sistem yang bertugas mengelola perangkat keras komputer (hardware), mengelola sumber daya perangkat lunak (software), dan menyediakan layanan umum untuk program komputer. Sistem Operasi berfungsi mengendalikan, mengontrol, serta memberikan koneksi antarperangkat keras komputer dengan pengguna.

Analogi Sederhana: Tubuh Manusia

Bayangkan komputer seperti tubuh manusia. Hardware adalah raga fisik (tangan, mata, otak fisik), sedangkan Sistem Operasi adalah nyawa dan sistem saraf pusatnya. Tanpa Sistem Operasi, laptop atau ponsel semahal apa pun hanyalah benda mati yang tidak bisa menerima perintah atau menjalankan aplikasi.

Bagaimana Sistem Operasi Dibangunkan? (5 Langkah Proses Booting)
Runut 1 s/d 5

Saat komputer baru dinyalakan, prosesor (CPU) belum berisi instruksi apa pun. Proses menyalakan komputer dan membangunkan Sistem Operasi hingga siap bekerja disebut Booting:

1 Listrik
Daya Dihidupkan

Aliran listrik masuk untuk membangunkan seluruh komponen perangkat keras.

2 Uji HW
POST (Self Test)

Komputer melakukan uji mandiri mengecek kondisi RAM, keyboard, & storage normal.

3 Firmware
Memuat BIOS/UEFI

Program dasar motherboard mencari lokasi partisi boot Sistem Operasi di disk.

4 Load OS
Memuat OS ke RAM

Kernel SO diangkut dari penyimpanan (SSD/HDD) ke memori utama RAM & CPU.

5 Ready
Pengalihan Kontrol

Hardware menyerahkan kendali penuh ke OS hingga layar desktop siap dipakai!

Uji Nyali Programmer 01:

1. Apa perbedaan mendasar antara Hardware dan Software beserta contohnya? • 2. Mengapa Microsoft Word tidak bisa berjalan tanpa OS? • 3. Apa yang terjadi pada tahap POST saat komputer dinyalakan?

BAB II Quest 02 • Alokasi 25 Menit

Model Lapisan Bawang & Jenis Sistem Operasi

Abstraksi Arsitektur Komputer dan Ragam Platform OS. Memahami mengapa manusia tidak menyentuh sirkuit fisik secara langsung dan bagaimana 4 varian platform OS disesuaikan dengan kebutuhan perangkat.

4. Penjelasan Model Lapisan Bawang (Onion Layer Model)

Arsitektur komputer berlapis dari inti terdalam (mesin) hingga kulit terluar (pengguna)

1 Inti Terdalam
Hardware (H)

Perangkat fisik mesin komputer seperti Terminals (layar/konsol), Printers, Disks (penyimpanan), RAM, dan CPU.

2 Jantung OS
Kernel (K)

Inti dari Sistem Operasi yang berhubungan langsung untuk mengatur dan mengontrol kerja seluruh Hardware fisik.

3 Antarmuka
Shell (S)

Kulit luar Sistem Operasi yang membungkus Kernel sebagai antarmuka (UI) tempat pengguna memberi perintah.

4 Kulit Terluar
Applications (A & U)

Program aplikasi dan program bantu (utilities) yang berinteraksi langsung dinikmati oleh manusia (pengguna).

Analogi Restoran (Model Lapisan Bawang):
1. Hardware: Kompor & alat masak fisik di dapur.
2. Kernel: Kepala Koki yang memasak langsung di kompor.
3. Shell: Pelayan / Buku Menu pencatat pesanan.
4. Applications: Hidangan lezat yang dinikmati tamu/pelanggan.

5. Jenis-Jenis Sistem Operasi (4 Kategori Utama)

Dirancang berbeda-beda menyesuaikan ukuran perangkat, daya listrik, dan tujuan penggunaan

Jenis OS Fungsi & Karakteristik Utama Contoh Nyata
Desktop OS Dirancang untuk komputer pribadi (PC/Laptop) guna menunjang pekerjaan sekolah, desain grafis, pemrograman, dan tugas perkantoran dengan tampilan layar lebar. Windows 10/11, macOS, Linux (Ubuntu, Fedora), ChromeOS
Mobile OS Dirancang khusus untuk perangkat bergerak (Smartphone/Tablet) dengan navigasi layar sentuh, manajemen hemat baterai, serta dukungan sensor gerak & GPS. Android, iOS, iPadOS, HarmonyOS
Embedded OS Sistem operasi berukuran kecil yang "tertanam" di dalam chip perangkat elektronik khusus. Hanya menjalankan satu fungsi spesifik secara otomatis dan hemat daya. Smart TV, mesin ATM, mesin cuci digital, smartwatch, rem mobil (ABS), router Wi-Fi
Server OS Dirancang untuk komputer pusat (server) yang melayani ribuan komputer pengguna (client) sekaligus selama 24 jam nonstop dengan stabilitas dan keamanan tinggi. Ubuntu Server, Red Hat Enterprise Linux, Windows Server, Debian
Cara Cepat Membedakan Embedded OS: Jika sebuah alat elektronik memiliki layar digital atau tombol pintar tetapi bukan HP dan bukan Laptop (misalnya mesin ATM, kasir minimarket, atau mesin cuci otomatis), maka alat tersebut menggunakan Embedded OS!
BAB III Quest 03 • Alokasi 30 Menit

Peran, Fungsi & Masalah Sistem Operasi

5 Peran Utama Pengelolaan Sumber Daya dan 6 Masalah yang Kerap Melanda OS. Memahami alur kerja RAM, penjadwalan Round Robin milidetik, siklus IPO, GUI/CLI, hingga pertolongan pertama Task Manager.

6. Lima (5) Peran dan Fungsi Utama Sistem Operasi

Alokasi Memori • Penjadwalan Round Robin • Siklus IPO • UI • Utilitas & Keamanan

A
Pengelolaan Memori (Memory Management)
RAM Control

Setiap aplikasi yang dibuka harus dimuat ke dalam RAM. Sistem Operasi bertugas membaca dan menulis data ke/dari suatu alamat memori, melacak kapasitas RAM yang tersedia, dan menentukan jatah ruang memori tiap aplikasi.

Analogi Resepsionis Hotel: Sistem Operasi mencatat Aplikasi A di kamar 001 dan Aplikasi B di kamar 002 agar datanya tidak saling menimpa, lalu segera mengosongkan kamar tersebut saat aplikasi ditutup pengguna.
B
Pengelolaan Proses (Multitasking & Penjadwalan Round Robin)
CPU Scheduler

Saat kita membuka banyak aplikasi sekaligus (Multitasking), bagian Sistem Operasi bernama Scheduler membagi waktu kerja CPU secara bergiliran menggunakan algoritma Round Robin (Time Sharing). CPU memberikan jatah waktu sangat kecil bernama Time Slice (misal: 2 milidetik) kepada setiap aplikasi.

// Contoh Kasus: CPU melayani 3 aplikasi mengantre di RAM (Time Slice = 2 ms)
1. Giliran 1 (0-2 ms) : CPU memproses Spotify → sisa 2 ms (Pindah mengantre ke belakang)
2. Giliran 2 (2-4 ms) : CPU memproses WhatsApp → sisa 0 ms (SELESAI DULUAN!)
3. Giliran 3 (4-6 ms) : CPU memproses Word → sisa 2 ms (Pindah mengantre ke belakang)
// Siklus berputar ribuan kali per detik sehingga tampak berjalan serempak bagi mata manusia!
Tahukah Kamu? Multitasking adalah kemampuan menjalankan banyak aplikasi sekaligus; Time Sharing adalah teknik membagi waktu giliran CPU; sedangkan Pipelining adalah teknik pemrosesan tahapan instruksi secara estafet di dalam CPU.
C
Pengelolaan Antarmuka Kernel Hardware (Siklus IPO)
Device Driver

Perangkat keras dari berbagai merek (printer Canon, mouse Logitech, kartu grafis NVIDIA) berbicara menggunakan bahasa mesin yang rumit. Kernel bersama Device Driver bertugas menjadi penerjemah antara aplikasi dan hardware dalam siklus Input - Proses - Output.

1. Input: Kamu mengetik huruf 'A' pada keyboard di Microsoft Word.
2. Proses: Sistem Operasi menangkap sinyal interupsi listrik untuk diolah CPU & RAM.
3. Output: OS memerintahkan driver monitor merender tampilan visual huruf 'A' di layar.
D
Interaksi Pengguna (User Interface)
GUI vs CLI

Sistem Operasi menyediakan dua jenis antarmuka untuk menerima instruksi manusia:

1. GUI (Instruksi Simbolik): Berinteraksi via jendela, ikon, kursor mouse, dan sentuhan. Contoh: Desktop Windows, layar Android.
2. CLI (Instruksi Tekstual): Berinteraksi langsung mengetikkan baris perintah teks. Contoh: CMD, PowerShell, Terminal Linux.
E
Penyediaan Utilitas & Keamanan
Utilities

Program bantu bawaan untuk merawat komputer dan mengarsipkan dokumen:

• Pengelolaan File: Menyimpan, menyalin (copy), mengurutkan (sort), dan menghapus file/folder di File Explorer.
• Pemantauan & Keamanan: Memantau beban CPU/RAM di Task Manager, kata sandi, Firewall, dan proteksi jaringan Wi-Fi/LAN.
Ringkasan 5 Kata Kunci Peran Sistem Operasi: (1) Mengatur alamat RAM • (2) Menggilir kerja CPU (Round Robin) • (3) Menerjemahkan Kernel Hardware • (4) Menyediakan tampilan GUI/CLI • (5) Menyediakan Utilitas File & Keamanan.

7. Masalah-Masalah dalam Sistem Operasi & Solusinya

Enam (6) gangguan yang sering terjadi akibat beban berlebih, konflik software, atau hardware

01 Membeku
Hang / Freeze (Not Responding)

Gejala: Tampilan aplikasi membeku, kursor macet/tidak bisa diklik.
Penyebab: Aplikasi memproses beban terlalu berat atau mengalami bug kode sehingga gagal membalas sinyal OS.

02 Saling Kunci
Deadlock (Saling Mengunci)

Gejala: Dua atau lebih program berhenti total di saat bersamaan.
Penyebab: Aplikasi A dan B saling menunggu sumber daya (RAM/file) yang sedang dipakai satu sama lain (seperti 2 mobil berhadapan di jembatan sempit).

03 RAM Penuh
Thrashing (Kehabisan RAM)

Gejala: Komputer menjadi sangat lambat ("lola") dan lag parah saat pindah aplikasi.
Penyebab: Terlalu banyak aplikasi berat dibuka melampaui RAM; SO kelelahan memindahkan data bolak-balik RAM dan SSD/HDD.

04 Crash Fatal
System Crash / BSOD / Bootloop

Gejala: Layar biru (Blue Screen of Death) di Windows, atau HP berhenti di logo (Bootloop).
Penyebab: Kerusakan fatal pada Kernel, file sistem rusak saat booting, atau keping RAM cacat fisik.

05 Driver HW
Masalah Driver Hardware

Gejala: Printer baru tidak terdeteksi, suara speaker hilang, atau Wi-Fi tiba-tiba mati.
Penyebab: Sistem Operasi belum memiliki atau kehilangan program penerjemah (Device Driver) yang cocok.

06 Keamanan
Infeksi Malware & Virus

Gejala: Iklan pop-up muncul sendiri, file terkunci ransomware, pemakaian CPU 100% tanpa sebab.
Penyebab: Masuknya program jahat yang menyusup ke celah keamanan OS untuk membajak sistem.

Solusi Pertolongan Pertama saat Sistem Operasi Bermasalah:

Jika sebuah aplikasi mengalami Not Responding, Lag Parah, atau Deadlock, pengguna dapat membuka utilitas Task Manager dengan menekan kombinasi tombol Ctrl + Shift + Esc di Windows, memilih aplikasi yang macet, lalu menekan tombol End Task agar Sistem Operasi mematikan proses tersebut dan membebaskan kapasitas memori RAM!

Kamus Istilah Penting Sistem Operasi

Booting: Proses menghidupkan komputer & memuat SO ke RAM.
Kernel: Inti terdalam SO pengontrol langsung hardware.
Shell: Lapisan pembungkus Kernel sebagai antarmuka perintah.
Round Robin: Algoritma penjadwalan giliran waktu CPU (time slice).
Device Driver: Program penerjemah bahasa hardware ke Sistem Operasi.
Thrashing: Penurunan performa drastis akibat RAM penuh.
Deadlock: Macet total karena 2 program saling tunggu sumber daya.
Embedded OS: Sistem Operasi tertanam di chip mesin elektronik khusus.
