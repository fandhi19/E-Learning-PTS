3. Pengertian Sistem Operasi (SO)
Sistem Operasi (Operating System / OS) adalah perangkat lunak sistem yang bertugas mengelola
perangkat keras komputer (hardware), mengelola sumber daya perangkat lunak (software), dan
menyediakan layanan umum untuk program komputer. Sistem Operasi berfungsi mengendalikan,
mengontrol, serta memberikan koneksi antarperangkat keras komputer dengan pengguna.
A N A L O G I  SE DE R HA N A :  T UBUH MA N USI A
Bayangkan komputer seperti tubuh m anusia. Hardware adalah raga fisik (tangan, mata, kaki),
sedangkan Sistem Operasi adalah ny awa dan sistem  saraf pusatny a. Tanpa Sistem Operasi, laptop
atau ponsel semahal apa pun hanyalah benda mati yang tidak bisa menjalankan aplikasi.
Bagaimana Sistem Operasi Dibangunkan? (Proses Booting)
Saat komputer baru dinyalakan, CPU belum berisi program apa pun. Proses menyalakan komputer dan
membangunkan Sistem Operasi hingga siap bekerja disebut Booting. Terdapat 5 langkah penting saat
proses Booting:
U J I  N Y A L I  P RO G RA M M E R 0 1
1. Jelaskan perbedaan mendasar antara Hardware dan Software beserta masing-masing 3 contohny a!
2. Mengapa aplikasi seperti Microsoft Word atau game tidak bisa langsung dijalankan di komputer y ang
belum memiliki Sistem Operasi?
3. Apa y ang terjadi pada tahap POST  saat komputer baru saja diny alakan (booting)?
Day a (Power) Dihidupkan: Aliran listrik masuk untuk membangunkan seluruh komponen perangkat
keras.
1
POST  (Power On Self Test): Komputer melakukan uji mandiri untuk mengecek apakah RAM,
keyboard, dan penyimpanan normal.
2
Mem uat BIOS (Basic Input Output System ): Program dasar pada motherboard dijalankan untuk
mencari lokasi Sistem Operasi.
3
Mem uat Sistem  Operasi: Sistem Operasi diangkut dari penyimpanan (SSD/HDD) ke dalam memori
utama (RAM) dan CPU.
4
Pengalihan Kontrol: Perangkat keras menyerahkan kendali penuh kepada Sistem Operasi hingga
layar utama siap digunakan.

6. Peran dan Fungsi Utama Sistem Operasi
a. Memori → b. Proses (Round Robin) → c. Kernel I/O → d. UI → e. Utilitas
F UN G SI  A
Pengelolaan Memori (Memory Management)
Setiap aplikasi y ang dibuka harus dimuat ke dalam RAM. Sistem Operasi bertugas m em baca dan
m enulis data ke/dari suatu alam at m em ori, melacak kapasitas RAM, dan menentukan jatah
memori tiap aplikasi.
Analogi Resepsionis Hotel: Sistem Operasi mencatat Aplikasi A di kamar 001 dan Aplikasi B di kamar
002 agar datany a tidak saling menimpa, lalu mengosongkan kamar saat aplikasi ditutup.
F UN G SI  B
Pengelolaan Proses (Multitasking & Penjadwalan Round Robin)
Saat kita membuka bany ak aplikasi sekaligus (Multitasking), bagian Sistem Operasi bernama Scheduler
membagi waktu kerja CPU secara bergiliran (T im e Sharing) menggunakan algoritma Round Robin:
Setiap aplikasi diberi jatah waktu kecil y ang sama (Time Quantum / Time Slice, misalny a 2 m ilidetik).
Jika waktu habis dan tugas belum selesai, aplikasi wajib mengantre kembali ke belakang dan CPU beralih
melay ani aplikasi berikutny a.
// Simulasi Penjadwalan CPU Metode Round Robin (Time Quantum = 2 ms)
ANTREAN_RAM : [Spotify (6 ms), WhatsApp (2 ms), Word (4 ms)]
1.  Giliran 1 (0-2 ms) : CPU memproses Spotify → sisa 4 ms (Pindah ke belakang)
2.  Giliran 2 (2-4 ms) : CPU memproses WhatsApp → sisa 0 ms (SELESAI!)
3.  Giliran 3 (4-6 ms) : CPU memproses Word → sisa 2 ms (Pindah ke belakang)
4.  // Berputar ribuan kali per detik sehingga semua aplikasi tampak berjalan serentak!
T A HUK A H K A MU?  ( MUL T I T A SK I N G  V S T I ME  SHA R I N G  V S P I P E L I N I N G )
Multitasking adalah kemampuan menjalankan banyak aplikasi sekaligus; T im e Sharing adalah
teknik membagi jatah waktu CPU secara bergiliran; sedangkan Pipelining adalah teknik "ban berjalan"
di dalam komponen internal CPU untuk mengeksekusi tahapan instruksi secara estafet.

Pengelolaan Antarmuka dengan Kernel Hardware (Siklus Input-Proses-Output)
Perangkat keras dari berbagai merek (printer Canon, mouse Logitech, kartu grafis NVIDIA) berbicara

F UN G SI  D

Tanpa antarmuka pengguna, manusia akan kesulitan memberi perintah ke komputer. Sistem Operasi
meny ediakan dua jenis User Interface:
1. I NST RUKSI  SI MBOLI K / GUI
Graphical User Interface: Berinteraksi
menggunakan ikon gambar, jendela (window),
menu, klik kursor mouse, atau sentuhan jari.
Contoh: Tampilan desktop Windows dan lay ar

2. I NST RUKSI  T EKST UA L / CLI
Com m and Line Interface: Berinteraksi
dengan mengetikkan baris perintah teks secara
langsung melalui key board. Contoh: Command
Prompt (CMD), PowerShell, dan Terminal Linux.
F UN G SI  E
Penyediaan Utilitas (Utilities), Pengelolaan File & Keamanan
Sistem Operasi meny ediakan program bantu bawaan (utilities) untuk merawat sistem komputer dan
mengelola pengarsipan:
• Pengelolaan File: Meny impan (save), meny alin (copy), mengurutkan (sort), memindahkan,
menamai, dan menghapus (delete) file/folder lewat File Explorer.
• Pem antauan & Keam anan: Memantau kinerja RAM/CPU lewat Task Manager, mengatur akun kata
sandi (password), perlindungan Firewall, serta koneksi jaringan Wi-Fi/LAN.
R I N G K A SA N  5  P E R A N  SI ST E M O P E R A SI
Ingat 5 kata kunci peran Sistem Operasi: (1) Mengatur alam at RAM, (2) Menggilir kerja CPU

GUI/CLI, dan (5) Meny ediakan Utilitas File & Keam anan.

7. Masalah-Masalah dalam Sistem Operasi
Dalam pemakaian sehari-hari, Sistem Operasi dapat mengalami gangguan akibat beban berlebih, konflik
perangkat lunak, maupun kerusakan komponen. Berikut adalah 6 masalah utama dalam Sistem
Operasi:
1. HA NG / FREEZE (NOT  RESPONDI NG)
Gejala: Tampilan aplikasi membeku dan kursor
tidak bisa diklik.
Peny ebab: Aplikasi memproses beban terlalu
berat atau mengalami bug sehingga gagal
membalas siny al panggilan dari Sistem Operasi.
2. DEA DLOCK (SA LI NG MENGUNCI )
Gejala: Dua atau lebih program berhenti total di
saat bersamaan.
Peny ebab: Aplikasi A dan Aplikasi B saling
menunggu sumber day a (RAM/file) y ang sedang
dipakai satu sama lain, seperti 2 mobil
berhadapan di jembatan sempit.
3. T HRA SHI NG (KEHA BI SA N RA M)
Gejala: Komputer menjadi sangat lambat ("lola")
dan lag parah saat pindah aplikasi.
Peny ebab: Terlalu bany ak aplikasi berat dibuka
hingga melampaui kapasitas RAM, membuat SO
kelelahan memindahkan data bolak-balik antara
RAM dan SSD/HDD.
4. SY ST EM CRA SH / BSOD / BOOT LOOP
Gejala: Lay ar biru (Blue Screen of Death) di
Windows lalu restart sendiri, atau HP berhenti di
logo (Bootloop).
Peny ebab: Kerusakan fatal pada lapisan
Kernel, file sistem rusak saat booting, atau
kerusakan fisik RAM/peny impanan.
5 . MA SA LA H DRI V ER HA RDWA RE
Gejala: Printer baru tidak terdeteksi, suara
speaker hilang, atau Wi-Fi mati.
Peny ebab: Sistem Operasi belum memiliki atau
kehilangan program penerjemah (Dev ice
Driv er) y ang cocok untuk perangkat keras
tersebut.
6. I NFEKSI  MA LWA RE & V I RUS
Gejala: Muncul iklan sendiri, file terkunci, atau
pemakaian CPU/RAM 100% tanpa sebab.
Peny ebab: Masukny a program jahat (virus,
trojan, ransomware) y ang meny usup ke celah
keamanan Sistem Operasi untuk membajak
sistem.
SO L USI  P E R T O L O N G A N  P E R T A MA  SA A T  SI ST E M O P E R A SI  BE R MA SA L A H
Jika sebuah aplikasi mengalami Not Responding atau Deadlock, pengguna dapat membuka utilitas T ask
Manager ( Ctrl + Shift + Esc  di Windows), memilih aplikasi yang macet, lalu menekan tombol End
T ask agar Sistem Operasi menghentikan proses tersebut dan membebaskan ruang di RAM.

menunggu sumber day a y ang sedang dipakai satu sama

Dev ice Driv er

Em bedded OS

Hardware

Kernel
Inti terdalam dari Sistem Operasi y ang berhubungan

Multitasking
Kemampuan Sistem Operasi menjalankan beberapa
aplikasi secara bersamaan.
Pipelining
Teknik di dalam prosesor (CPU) untuk memproses

RAM

Algoritma penjadwalan CPU y ang membagi jatah

Shell
