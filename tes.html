Skenario Kasus — Kalkulator Komputer Rara
Data uji: 25 + 15 = 40

Rara sedang mengerjakan tugas Matematika. Ia menggunakan aplikasi kalkulator di komputernya. Rara mengetik 25 + 15 di keyboard. Kurang dari satu detik, di layar monitor muncul angka 40.

Instruksi Simulasi
  1. 1Gambarkan bagaimana data 25 + 15 bergerak di dalam mesin komputer Rara sampai menghasilkan angka 40.
  2. 2Gambarkan arah panah yang menghubungkan kotak-kotak komponen di bawah ini secara berurutan (dari Langkah 1 hingga Langkah 4).
  3. 3Isilah titik-titik pada kolom penjelasan di halaman berikutnya untuk menceritakan proses perpindahan datanya!

Tugas 2 — Detektif Jalur Data (2/2)

Mengukur TP 2 · Menuliskan Kronologi Alur Data

Kronologi Alur Data

Isilah titik-titik di bawah ini sesuai dengan pemahaman kelompokmu tentang alur data 25 + 15 = 40!

Langkah Demi Langkah
1
Keyboard (Input) mengirimkan data 25, perintah +, dan 15 menuju ke untuk disimpan sementara.
2
(Si Koki) mengambil data dan perintah tersebut dari RAM, lalu melakukan proses perhitungan matematika (menjumlahkannya menjadi 40).
3
⚠️ Awas Jebakan Von Neumann!
Setelah proses selesai, CPU TIDAK BOLEH mengirimkan hasilnya langsung ke Monitor. CPU harus mengembalikan / menyimpan hasil angka 40 kembali ke .
4
Terakhir, barulah mengirimkan data hasil akhir (40) tersebut ke perangkat Output (Monitor) untuk ditampilkan kepada Rara.
💡 Ingat Aturan Emas Von Neumann
  • 1Semua data wajib lewat RAM. Input ➜ RAM ➜ CPU ➜ RAM ➜ Output.
  • 2CPU tidak boleh menyentuh Input/Output secara langsung. Tugas CPU hanya mengolah data dari RAM.
  • 3Hasil perhitungan selalu dikembalikan ke RAM sebelum diteruskan ke layar.
Checklist Selesai — Tugas 2
  • Keempat langkah kronologi sudah terisi dengan komponen yang benar
  • Sudah memahami mengapa CPU harus mengembalikan hasil ke RAM (bukan langsung ke layar)
  • Sudah bisa menjelaskan alur I-P-O dengan bahasa kelompok sendiri
