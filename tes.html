Tahap 1: Arsitektur Data Source
01

Tahap 1 — Merancang Basis Data Excel (Data Source)

Aplikasi: Microsoft Excel · Bobot: 20 Poin · Alokasi: 20 Menit

Skenario Proyek: Daftar Penerima Undangan Rapor Studi Kasus SMAN 4

Sebagai staf IT sekolah, Anda ditugaskan menyusun basis data penerima surat undangan pengambilan rapor semester ganjil untuk minimal 10 siswa. Ikuti instruksi langkah kerja di bawah ini:

1
Buka aplikasi Microsoft Excel, buat workbook baru. Simpan berkas dengan nama: Data_Siswa_XE6.xlsx pada folder kerjamu.
2
Ubah nama sheet (rename tab) dari Sheet1 menjadi Data_Rapor.
3
Ketik 7 Kolom Header tepat di Baris 1 (tanpa baris kosong dan tanpa merged cell): No_Presensi, NISN, Nama_Siswa, Kelas, Nama_Wali, Ruang_Kelas, Tanggal_Ambil, Biaya_Komite.
4
Untuk kolom NISN, awali pengetikan dengan tanda petik satu ('), contoh: '0081234567 agar digit 0 paling depan tidak hilang.

📋 Audit 4 Aturan Emas Data Source (Verifikasi Sebelum ke Word) Wajib Ceklis

Centang kotak di bawah ini setelah Anda memeriksa berkas Excel Anda:

Aturan 1: Header kolom berada tepat di Baris 1 (tanpa judul di atasnya).
Aturan 2: Tidak ada sel yang digabung (Merged Cells) pada tabel.
Aturan 3: Tidak ada baris atau kolom kosong di tengah-tengah data.
Aturan 4: Tipe data seragam & file Excel sudah disimpan dan ditutup (Close).

Tahap 2 & 3: Word Master & Mailings
02

Tahap 2 & 3 — Desain Naskah Master & Integrasi Mailings

Aplikasi: Microsoft Word · Bobot: 25 Poin · Alokasi: 25 Menit

Langkah Pembuatan Dokumen Master (Undangan_Rapor_Patbhe.docx) Template Surat
1
Buka Microsoft Word, atur ukuran kertas ke A4 dengan margin: Atas 2.5 cm, Bawah 2 cm, Kiri 2.5 cm, Kanan 2 cm. Simpan dengan nama Undangan_Rapor_Patbhe.docx.
2
Buat KOP Surat Resmi SMAN 4 Yogyakarta: Sisipkan logo sekolah, ketik identitas sekolah lengkap dengan font Times New Roman / Arial, lalu beri garis pembatas ganda (Bottom Border: Double Line).
3
Tulis struktur surat dinas: Nomor Surat (421/UND/2026), Lampiran (-), Perihal (Undangan Pengambilan Laporan Hasil Belajar), Tanggal Surat, Salam Pembuka, Paragraf Pembuka, dan Paragraf Penutup.
Langkah Menghubungkan File Excel ke Word (Select Recipients) Tab Mailings

Alur Klik: Tab Mailings → grup Start Mail Merge → klik Select Recipients → pilih Use an Existing List... → arahkan ke file Data_Siswa_XE6.xlsx → pilih tabel Data_Rapor$ → centang "First row of data contains column headers" → klik OK.

Penyisipan Penanda Data (Merge Field) pada Naskah:

Gunakan menu Insert Merge Field untuk meletakkan kode kurung siku ganda «...» pada titik yang sesuai:

Elemen Surat di Word Nama Merge Field yang Dipanggil Tampilan Hasil Pratinjau (Preview Results)
Kepada Yth. Bapak/Ibu: «Nama_Wali» Bambang Haryadi
Nama Peserta Didik: «Nama_Siswa» Agus Haryadi
NISN / No. Presensi: «NISN» / «No_Presensi» 0081122331 / 1
Kelas Siswa: «Kelas» X-E6
Ruang Pengambilan Rapor: «Ruang_Kelas» Ruang 101
🔍 Uji Coba Preview Results & Pemeriksaan Navigasi Data Verifikasi Data

Klik tombol Preview Results pada tab Mailings. Uji tombol navigasi record < dan > untuk memastikan setiap record berganti secara mulus:

Data Record 1 muncul atas nama Agus Haryadi.
Data Record 2 muncul atas nama Dewi Lestari.
Digit 0 pada nomor NISN tetap utuh terbaca (tidak terpotong).
Format spasi dan tanda koma antar field tertata rapi.

Tahap 4 & 5 — Logika Rules, Switch Codes & Finish Merge

Fitur Lanjutan · Bobot: 30 Poin · Alokasi: 25 Menit

Langkah Praktik 4A: Logika Percabangan (Rules If... Then... Else...) Fitur Logika

Dalam naskah surat, panitia ingin menampilkan instruksi khusus secara dinamis jika wali murid diarahkan ke ruang laboratorium komputer:

Instruksi Klik: Tab Mailings → grup Write & Insert Fields → klik Rules → pilih If... Then... Else....
Parameter Dialog Rules Isian Konfigurasi Praktik Siswa
Field name: Ruang_Kelas
Comparison: Equal to (Sama dengan)
Compare to: Lab Komputer 1
Insert this text: *Catatan: Harap melepas alas kaki sebelum memasuki ruang laboratorium komputer.
Otherwise insert this text: *Catatan: Silakan langsung menuju ruang kelas masing-masing sesuai nomor ruang.
Langkah Praktik 4B: Kode Pengubah Format (Switch Codes — Alt + F9) Formatting Code

Secara default, data tanggal dari Excel sering muncul format angka murni (misal: 12/18/2026) dan nominal uang tanpa tanda rupiah. Modifikasi kode field menggunakan tombol pintasan Alt + F9:

1. Format Tanggal Standar Bahasa Indonesia (18 Desember 2026):
{ MERGEFIELD Tanggal_Ambil \@ "dd MMMM yyyy" }
2. Format Mata Uang Rupiah Resmi (Rp 150.000,00):
{ MERGEFIELD Biaya_Komite \# "Rp #,##0.00" }

*Catatan: Setelah mengetik kode di atas, tekan kembali Alt + F9 untuk menutup kode, lalu tekan F9 untuk memperbarui tampilan.

Tahap 5: Cetak Gabung Akhir ke Berkas PDF (Finish & Merge) Ekspor PDF
1
Klik tombol Finish & Merge pada tab Mailings paling kanan → pilih Print Documents....
2
Pilih opsi All (semua record penerima) → klik OK.
3
Pada kotak dialog Printer, pilih Microsoft Print to PDF → simpan berkas dengan format penamaan resmi: PRAKTIK_MM_[KELAS]_[ABSEN]_[NAMA].pdf. Pastikan berkas PDF yang dihasilkan memiliki 10 halaman utuh.
