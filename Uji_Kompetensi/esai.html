Daftar Soal Esai / Uraian Resmi

3 Butir Soal (Total 50 Poin)
ESAI 1
DIAGRAM ALIR (FLOWCHART) • C6 KREASI

Membuat Flowchart 2 Percabangan: Kasus Cek Kelulusan Ujian

Skor: 15 Poin

Buatlah sebuah Diagram Alir (Flowchart) dengan 2 jalur percabangan (Ya dan Tidak) untuk kasus Cek Kelulusan Ujian dengan aturan berikut:

  • Program menerima masukan berupa NILAI.
  • Jika NILAI >= 75, maka program mencetak "LULUS".
  • Jika di bawah 75 (Tidak), maka program mencetak "TIDAK LULUS".
  • (Gunakan simbol standar yang tepat: Terminator, Input/Output, Decision, dan Flowline!)
Rubrik Penilaian Guru:
• Menggunakan simbol Start/End dan Input/Output dengan benar (5 poin)
• Menggunakan simbol Belah Ketupat (Decision) dengan kondisi NILAI >= 75? (5 poin)
• Membagi menjadi 2 jalur cabang (Ya dan Tidak) dengan hasil cetak yang tepat (5 poin)
ESAI 2
PSEUDOCODE (KODE SEMU) • C6 KREASI

Membuat Pseudocode 3 Percabangan: Penentuan Grade Nilai Siswa

Skor: 15 Poin

Buatlah sebuah Pseudocode yang menerapkan 3 kondisi percabangan (IF - ELSE IF - ELSE IF - ELSE) untuk menentukan Grade Nilai Siswa dengan aturan berikut:

  • Jika nilai >= 90, cetak "A"
  • Jika nilai >= 80, cetak "B"
  • Jika nilai >= 70, cetak "C"
  • Selain itu (di bawah 70), cetak "D"
Rubrik Penilaian Guru:
• Menuliskan struktur deklarasi dan INPUT nilai (3 poin)
• Menuliskan 3 kondisi pengecekan (>= 90, >= 80, >= 70) menggunakan IF dan ELSE IF secara berurutan (8 poin)
• Menuliskan penutup ELSE (cetak "D") dan ENDIF dengan indentasi rapi (4 poin)
ESAI 3
ARSITEKTUR VON NEUMANN • C4 ANALISIS

Contoh Cara Kerja Arsitektur Von Neumann dalam Mengeksekusi Instruksi

Skor: 20 Poin

Jelaskan dengan bahasamu sendiri bagaimana cara kerja arsitektur komputer Von Neumann (melibatkan komponen Input, RAM, Control Unit, ALU, Register, Bus, dan Output) dengan memberikan satu contoh kasus sederhana, misalnya saat pengguna menghitung penjumlahan 5 + 3 pada komputer!

Rubrik Penilaian Guru:
• Menuliskan contoh kasus konkret (misal 5 + 3) (4 poin)
• Menjelaskan peran RAM dan Bus dalam menampung serta mengalirkan instruksi/data (5 poin)
• Menjelaskan peran CU dan ALU dalam siklus Fetch - Decode - Execute (6 poin)
• Menjelaskan tahap Store dan penyajian hasil ke Output (5 poin)
