Struktur Data: Stack & Queue

Pahami cara komputer mengorganisasi data. Dari tumpukan riwayat browser hingga antrean print dokumen.

Pengertian Struktur Data

Struktur data adalah cara untuk menyimpan, mengatur, dan mengelola data sehingga data tersebut dapat digunakan dengan lebih mudah dan efisien.

Contoh Sederhana dalam Kehidupan Sehari-hari:

  • Daftar nama siswa: Data disusun dalam urutan tertentu.
  • Tumpukan buku: Buku disusun bertumpuk.
  • Antrean siswa di kantin: Siswa menunggu berdasarkan urutan kedatangan.

Nah, Stack dan Queue merupakan contoh struktur data yang memiliki aturan tertentu dalam memasukkan dan mengambil data.

Stack (Tumpukan)

LIFO: Last In, First Out

Data yang terakhir masuk akan menjadi data yang pertama keluar (Yang terakhir masuk → keluar terlebih dahulu).

🥞 Analogi Stack (Tumpukan Piring)

LIFO (Last In, First Out)

Proses masuk dan keluar data hanya dilakukan dari satu pintu: bagian paling atas (TOP).

↓ Push (Masuk) | ↑ Pop (Keluar)
Piring C TOP
Piring B Tengah
Piring A BOTTOM (Pertama ditaruh)

Operasi Utama pada Stack:

  • 1. Push: Menambahkan data ke bagian atas Stack (Contoh: Push A, Push B, Push C).
  • 2. Pop: Mengambil/menghapus data paling atas (C keluar terlebih dahulu).
  • 3. Peek / Top: Melihat data paling atas tanpa menghapusnya (Hasilnya: C).
  • 4. IsEmpty: Memeriksa apakah Stack kosong (Menghasilkan True jika kosong).

Queue (Antrean)

FIFO: First In, First Out

Data yang pertama masuk akan menjadi data yang pertama keluar (Yang datang duluan → dilayani duluan).

🎟️ Analogi & Operasi Queue (Antrean)

FIFO (First In, First Out)
← DEQUEUE (Keluar Pertama) ENQUEUE (Masuk Akhir) ←
FRONT
Elemen A
ANTREAN
Elemen B
REAR
Elemen C

Operasi Utama pada Queue:

  • 1. Enqueue: Menambahkan data ke belakang Queue (A → B → C).
  • 2. Dequeue: Mengambil/menghapus data dari depan Queue (A keluar terlebih dahulu).
  • 3. Front: Melihat data paling depan Queue (Front = A).
  • 4. Rear: Melihat data paling belakang Queue (Rear = C).

Contoh Stack dalam Kehidupan

  • 📚
    Tumpukan buku: Buku terakhir yang ditaruh di atas akan diambil terlebih dahulu.
  • 🍽️
    Tumpukan piring: Piring terakhir ditaruh menjadi piring pertama yang diambil.
  • ↩️
    Tombol Undo: Mengetik A → B → C. Saat Undo ditekan, C dibatalkan terlebih dahulu.
  • 🌐
    Tombol Back Browser: Halaman terakhir yang dikunjungi (Google → YouTube → Wikipedia) akan ditinggalkan terlebih dahulu.

Contoh Queue dalam Kehidupan

  • 🏧
    Antrean ATM: Orang yang datang lebih dahulu akan dilayani lebih dahulu.
  • 🏥
    Antrean pendaftaran: Pasien yang datang lebih awal mendapat giliran lebih dahulu.
  • 🍔
    Antrean makanan: Andi → Budi → Citra → Deni. Andi dilayani pertama.
  • 🖨️
    Antrean pencetak dokumen: Dokumen A, B, C, D dicetak printer sesuai urutan masuk.
  • 💻
    Sistem Komputer: Mengatur pemrosesan tugas yang antre secara berurutan.

Perbedaan & Perbandingan Ringkas

Tabel komparasi prinsip dan logika data Stack vs Queue

Stack (Tumpukan) 🥞

  • Prinsip: LIFO (Last In, First Out)
  • Data keluar: Data terakhir masuk
  • Menambah data: Dari atas (Push)
  • Mengambil data: Dari atas (Pop)
  • Analogi utama: Tumpukan piring / buku

Queue (Antrean) 🧑‍🤝‍🧑

  • Prinsip: FIFO (First In, First Out)
  • Data keluar: Data pertama masuk
  • Menambah data: Dari belakang (Enqueue)
  • Mengambil data: Dari depan (Dequeue)
  • Analogi utama: Antrean kasir / kantin

Contoh Simulasi Data Masuk: A → B → C

Jika menggunakan STACK (LIFO):

Masuk: A → B → C

Keluar: C → B → A

Jika menggunakan QUEUE (FIFO):

Masuk: A → B → C

Keluar: A → B → C

Stack & Queue dalam Pemrograman

Penerapan nyata dan simulasi eksekusi logika kode

STACK = [10, 20, 30]

Anggap 30 berada di posisi paling atas (TOP).

Jika dilakukan: Pop()
Maka yang keluar: 30
Sisa Stack: [10, 20]

Kegunaan Pemrograman: Undo/Redo, riwayat fungsi, navigasi Back, pengecekan tanda kurung.

QUEUE = [10, 20, 30]

Anggap 10 berada di posisi depan (FRONT).

Jika dilakukan: Dequeue()
Maka yang keluar: 10
Sisa Queue: [20, 30]

Kegunaan Pemrograman: Antrean printer, antrean tugas CPU, pemrosesan data berurutan.

Kesimpulan (Cara Mudah Mengingat)

STACK = TUMPUKAN 🥞

Prinsip: LIFO (Last In, First Out)

Terakhir masuk → Pertama keluar

Operasi Utama: Push → Pop → Peek

QUEUE = ANTREAN 🧑‍🤝‍🧑

Prinsip: FIFO (First In, First Out)

Pertama masuk → Pertama keluar

Operasi Utama: Enqueue → Dequeue → Front/Rear
