BAGIAN 1

Konsep Dasar Algoritma

1. Pengertian Algoritma

Secara sederhana, Algoritma adalah urutan langkah-langkah logis, terstruktur, dan terbatas yang disusun secara sistematis untuk menyelesaikan suatu masalah atau mencapai tujuan tertentu.

Analogi Kehidupan Sehari-hari: Membuat Mie Instan

Pikirkan algoritma seperti resep masakan atau petunjuk merakit furnitur:

Masalah / Input:

Ingin menyajikan Mie Instan siap makan.

Langkah Algoritma:
  1. Rebus 400 ml air hingga mendidih.
  2. Masukkan mie ke dalam air mendidih selama 3 menit.
  3. Tuang bumbu ke dalam piring.
  4. Tiriskan mie dan campur dengan bumbu di piring.
  5. Mie siap disajikan (Output).

⚠️ Penting: Jika urutan diacak (misal: bumbu dituang sebelum air direbus, atau mie tidak direbus), hasilnya tidak akan sesuai. Komputer bekerja persis seperti ini: harus mengikuti instruksi yang berurutan dan logis.

2. Ciri-Ciri Algoritma yang Baik

Menurut ilmuwan komputer terkenal Donald E. Knuth, sebuah algoritma yang baik harus memenuhi 5 ciri utama:

Ada Input

Memiliki zero (0) atau lebih data yang dimasukkan untuk diproses oleh algoritma.

Ada Output

Menghasilkan minimal satu solusi / hasil akhir sebagai output pekerjaan.

Keterbatasan (Finiteness)

Algoritma harus berhenti setelah melakukan sejumlah langkah tertentu (tidak boleh infinite loop).

Kepastian (Definiteness)

Setiap langkah terdefinisi secara jelas, presisi, dan tidak menimbulkan makna ganda (ambigu).

Efektif (Effectiveness)

Setiap instruksi harus sederhana dan dapat dikerjakan secara rasional dalam waktu yang masuk akal.

BAGIAN 2

Diagram Alir (Flowchart)

1. Pengertian Flowchart

Flowchart (Diagram Alir) adalah representasi visual/grafis dari alur langkah-langkah algoritma menggunakan simbol-simbol geometris standar. Flowchart membantu developer melihat alur logika, keputusan, dan pemrosesan data secara intuitif.

2. Simbol-Simbol Standar Flowchart

Simbol Nama Deskripsi
Garis Alir (flowline) Arah yang menunjukkan aliran program dari awal hingga akhir.
Terminator Titik awal atau titik akhir suatu program.
Proses Suatu kegiatan komputasi yang dilakukan oleh program: misalnya operasi aritmatika.
Keputusan Merupakan titik percabangan yang salah satu cabangnya dapat dilalui oleh program berdasarkan suatu kondisi.
Masukan (Input) / Keluaran (Output) Melambangkan titik saat program akan menerima suatu data atau menghasilkan suatu informasi.
Subprogram Melambangkan suatu kegiatan atau proses lain yang telah didefinisikan sebelumnya.
Penghubung dalam Halaman Digunakan untuk menghubungkan suatu titik pada diagram alir ke titik lain pada halaman yang sama.
Penghubung antar Halaman Digunakan untuk menghubungkan suatu titik pada diagram alir ke titik lain pada halaman yang berbeda. Digunakan apabila diagram lain cukup kompleks sehingga tidak dapat digambar dalam satu halaman.

BAGIAN 3

Pseudocode (Kode Semu)

1. Pengertian Pseudocode

Pseudo = Semu / Tiruan | Code = Kode Pemrograman.
Pseudocode adalah cara penulisan algoritma yang menyerupai bahasa pemrograman, namun tetap menggunakan bahasa manusia yang mudah dibaca. Pseudocode bebas dari aturan sintaks komputer yang ketat.

2. Aturan & Format Penulisan Pseudocode

Struktur dasar penulisan pseudocode dibagi menjadi 3 bagian utama:

PROGRAM NamaProgram
// Penjelasan singkat tujuan program dibuat
DEKLARASI:
// Memperkenalkan nama variabel beserta tipe datanya
ALGORITMA:
// Urutan instruksi dan alur pemrosesan logika

3. Kata Kunci Standar Pseudocode

Membaca Input READ, INPUT, GET
Menampilkan Output PRINT, WRITE, DISPLAY
Pemberian Nilai ← atau =
Pengkondisian IF ... THEN ... ELSE

4. Contoh Pseudocode: Cek Kelulusan Siswa

PROGRAM CekKelulusanSiswa

DEKLARASI:
nilai : integer

ALGORITMA:
INPUT nilai
IF nilai >= 75 THEN
PRINT "Selamat, Anda LULUS!"
ELSE
PRINT "Maaf, Anda TIDAK LULUS."
ENDIF
BAGIAN 4

Pengenalan Bahasa Pemrograman (Bahasa C++)

1. Apa itu Bahasa Pemrograman C++?

Bahasa Pemrograman adalah himpunan instruksi standar untuk memerintah komputer. Komputer sebenarnya hanya memahami Bahasa Mesin (biner: 0 dan 1). Oleh karena itu, kode yang kita tulis dalam bahasa tingkat tinggi seperti C++ perlu diterjemahkan oleh program Compiler menjadi bahasa mesin agar dapat dieksekusi oleh Processor.

2. Anatomi / Struktur Dasar Kode C++

Perhatikan struktur kode C++ berikut beserta penjelasannya:

#include <iostream> // 1. Header Library (Untuk fungsi Input/Output cin & cout)
using namespace std; // 2. Namespace standar agar tidak perlu menulis std::

int main() { // 3. Fungsi Utama (Titik AWAL program dijalankan)
// 4. Badan Program (Instruksi-instruksi C++)
cout << "Halo, Selamat Belajar Koding C++!\n";

return 0; // 5. Mengembalikan 0 (Menandakan program selesai dengan sukses)
}

3. Konsep Penting dalam C++

A. Variabel & Tipe Data

Variabel adalah wadah di memori komputer untuk menyimpan data. Setiap variabel wajib ditentukan jenis Tipe Data-nya sebelum digunakan.

Tipe Data C++ Fungsi / Jenis Data Contoh Nilai
int Menyimpan bilangan bulat (tanpa koma) 10, -5, 100
float / double Menyimpan bilangan desimal (pecahan) 3.14, 75.5
char Menyimpan 1 karakter tunggal (diapit tanda petik satu) 'A', 'Z', '#'
string Menyimpan teks / kalimat (diapit tanda petik dua) "Siswa SMA", "Lulus"
bool Menyimpan nilai kebenaran logika true, false

B. Perintah Input & Output di C++

Output: cout <<

Digunakan untuk menampilkan teks atau isi nilai variabel ke layar monitor.

cout << "Nilai kamu: " << nilai;
Input: cin >>

Digunakan untuk membaca ketikan data dari keyboard pengguna ke dalam variabel.

cin >> nilai;

C. Contoh Program Lengkap C++: Kelulusan Ujian

Berikut adalah implementasi nyata dalam kode C++ dari studi kasus kelulusan yang telah dirancang pada Flowchart dan Pseudocode sebelumnya:

Program C++
#include <iostream>
using namespace std;

int main() {
int nilai; // Deklarasi variabel nilai

// Meminta input dari pengguna
cout << "Masukkan nilai ujian Anda: ";
cin >> nilai;

// Percabangan kondisi (Decision)
if (nilai >= 75) {
cout << "Selamat, Anda LULUS!" << endl;
} else {
cout << "Maaf, Anda TIDAK LULUS." << endl;
}

return 0;
}

Kesimpulan

Flowchart adalah jembatan komunikasi antara kebutuhan bisnis (non-teknis) dan implementasi teknis. Dengan simbol-simbol standar yang jelas, seluruh tim bisa memahami alur program sebelum satu baris kode pun ditulis. Itulah mengapa flowchart menjadi alat wajib dalam perancangan sistem.
