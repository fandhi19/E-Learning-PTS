TP 2

Perancangan Diagram Alir (Flowchart)

Rangkai diagram alir langsung di bawah ini dengan drag & drop simbol yang sesuai!

Panduan Simbol Flowchart:

Terminator (Oval)

Untuk Start dan End

Input/Output (Jajar Genjang)

Untuk baca & cetak

Decision (Belah Ketupat)

Untuk uji kondisi

Process (Persegi Panjang)

Untuk perhitungan

Cara Pakai Playground:

  • Klik simbol di palet kiri → muncul di canvas.
  • Drag simbol untuk mengatur posisi. Canvas akan otomatis memanjang jika flowchart-mu panjang.
  • Double-click pada teks untuk edit label.
  • Aktifkan Connect Mode → klik 2 simbol untuk panah penghubung.
  • Dari simbol Keputusan → akan muncul pilihan label Ya / Tidak di panah.
  • Tekan Delete untuk hapus simbol terpilih.
