Studi Kasus: Sistem Diskon Belanja "Patbhe Mart"

Kasus percabangan if-else sederhana

Kasir toko Patbhe Mart membutuhkan program otomatis untuk menghitung diskon belanja pelanggan. Berikut ketentuannya:

Kasir menginputkan total belanjaan pelanggan (Total_Belanja).

Jika Total_Belanja ≥ Rp100.000
  • Pelanggan mendapat diskon 10%
  • Tampilkan: "Selamat, Anda Mendapat Diskon 10%!"
  • Total_Bayar = Total_Belanja − Diskon
Jika Total_Belanja < Rp100.000
  • Pelanggan tidak mendapat diskon
  • Tampilkan: "Terima Kasih Telah Berbelanja!"
  • Total_Bayar = Total_Belanja

Panduan Simbol Flowchart:

Cara Pakai Playground:

  • Klik simbol di palet kiri → muncul di canvas.
  • Drag simbol untuk mengatur posisi.
  • Double-click pada teks untuk edit label (misal "Mulai", "Input Total_Belanja").
  • Aktifkan Connect Mode → klik 2 simbol untuk panah penghubung.
  • Dari simbol Keputusan → akan muncul pilihan label Ya / Tidak di panah.
  • Tekan Delete untuk hapus simbol terpilih.
