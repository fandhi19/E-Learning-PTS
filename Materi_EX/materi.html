Microsoft Excel: Tabel, Rumus & Grafik

Pelajari cara membuat folder kerja, menyusun tabel data terstruktur, menguasai rumus dasar (SUM, AVERAGE, MIN, MAX, COUNT, IF, COUNTIF), dan menyajikan data melalui grafik yang menarik.

BAGIAN 1

Pengenalan Microsoft Excel

1. Apa itu Microsoft Excel?

Microsoft Excel adalah program pengolah angka (spreadsheet) yang dikembangkan oleh Microsoft. Excel digunakan untuk mengelola, menghitung, menganalisis, dan menyajikan data dalam bentuk tabel maupun grafik.

Analogi Sederhana

Bayangkan Excel seperti buku besar kakek-nenek zaman dulu — tapi versi digital. Setiap halaman berisi kotak-kotak (cell) yang bisa diisi angka, teks, atau rumus. Bedanya, Excel menghitung otomatis dalam sekejap dan bisa membuat grafik dalam beberapa klik.

Dipakai di Dunia Nyata untuk Apa?

Rekap nilai — guru menyimpan nilai 40 siswa sekaligus
Keuangan pribadi — catat pemasukan & pengeluaran bulanan
Data penjualan — toko melihat produk mana yang laris
Absensi & jadwal — HRD mengelola karyawan

2. Bagian-Bagian Antarmuka Excel

Sebelum mulai, kenali dulu "isi perut" Excel. Ada 6 bagian utama yang akan sering kamu pakai:

1️⃣ Ribbon / Menu

Kumpulan tab perintah di atas (Home, Insert, Formulas, Data). Ini "dapur"-nya Excel.

2️⃣ Cells (Sel)

Kotak pertemuan baris & kolom. Tempat kamu mengetik angka/teks/rumus.

3️⃣ Kolom & Baris

Kolom = huruf (A, B, C...). Baris = angka (1, 2, 3...). Ini yang menentukan alamat sel.

4️⃣ Formula Bar (ƒx)

Menampilkan isi asli sel. Kalau sel berisi rumus, hasil muncul di sel tapi rumusnya muncul di sini.

5️⃣ Sheet Tabs

Tab di bawah (Sheet1, Sheet2...). Satu file bisa punya banyak lembar kerja — seperti buku dengan banyak halaman.

6️⃣ Name Box

Kotak kecil kiri atas yang menunjukkan alamat sel aktif (mis. A1, B5, D20).

Tips cepat: Kalau bingung mencari tombol, coba klik tiap tab di Ribbon dan baca nama-nama tombolnya. Excel menyusun menu sesuai "kebutuhan" — misalnya tab Formulas isinya semua tentang rumus.

3. Alamat Sel (Cell Reference)

Setiap sel punya alamat unik berdasarkan pertemuan kolom dan baris. Alamat inilah yang dipakai dalam rumus.

A B C
1 Nama Nilai Grade
2 Budi 85 A
3 Ani 92 A
4 Cici 78 B

Cara baca: Sel B2 = kolom B, baris 2 → berisi angka 85 (nilai Budi).

Cek cepat: Klik sel mana saja, lihat kotak Name Box kiri atas — di situ muncul alamat sel yang kamu klik.

Cara Cepat Pindah Sel

  • Panah ↑↓←→ — pindah satu sel ke arah panah
  • Tab — pindah ke kolom kanan
  • Enter — pindah ke baris bawah (setelah selesai edit)
  • Ctrl + Home — lompat ke sel A1
  • Ctrl + → — lompat ke ujung data di kanan
BAGIAN 2

Membuat Folder Kerja

Sebelum mulai bekerja, biasakan membuat folder khusus untuk menyimpan file. Ini supaya tugasmu tidak tercampur dengan file lain dan mudah ditemukan.

Kenapa ini penting? Banyak siswa kehilangan file karena tersimpan di Downloads lalu terhapus, atau nama filenya "Tugas.xlsx" sehingga tertimpa file lain. Folder yang rapi = nilai yang aman. 🛡️

Langkah Membuat Folder Kerja (Detail)

1

Buka File Explorer

File Explorer adalah "rumah" semua file di komputermu. Ada 3 cara membukanya:

  • Tekan Windows + E — cara tercepat
  • Klik ikon folder kuning di taskbar bawah
  • Klik Start menu → ketik "File Explorer"
2

Pilih Lokasi Penyimpanan

Klik salah satu di panel kiri: Documents (paling disarankan), Pictures, atau D: (kalau ada drive D).

Hindari: menyimpan di Downloads, Desktop, atau C:\Windows — file mudah hilang atau rusak.

3

Buat Folder Baru

Klik kanan di area kosong → pilih New → Folder. Folder baru akan muncul dengan nama ter-highlight (siap diganti).

Alternatif: tekan Ctrl + Shift + N — sama hasilnya.

4

Beri Nama Folder dengan Format Baku

Ketik nama sesuai format, lalu tekan Enter.

Benar

Tugas_Excel_Budi_15

Jelas: tugas apa, punya siapa, absen berapa

Salah

Tugas / asdf / New folder

Tidak jelas & mudah tertukar

5

Buat File Excel di Dalam Folder

Ada 2 cara:

  • Dari File Explorer: klik kanan di dalam folder → New → Microsoft Excel Worksheet → beri nama
  • Dari Excel: buka Excel → File → New → Blank Workbook → Ctrl+S → arahkan ke folder tadi
6

Simpan Rutin (Kebiasaan Emas)

Biasakan tekan Ctrl+S setiap 3-5 menit. Ini mencegah kehilangan pekerjaan kalau listrik mati atau laptop hang.

Ekstra: Simpan juga ke Google Drive/OneDrive sebagai backup gratis — kalau laptop rusak, file tetap aman.

Tips pro: Buat folder induk "Tugas_SMA_XE6" dulu, lalu di dalamnya bikin sub-folder per mata pelajaran. Semester depan tinggal buka folder yang sama — semua rapi dari awal.

BAGIAN 3

Membuat Tabel Data

Tabel yang baik punya baris header yang jelas dan data terstruktur. Contoh: tabel nilai siswa dengan kolom Nama, MTK, B.Indo, B.Ing.

Target Akhir: Contoh Tabel

Inilah tabel yang akan kita bangun langkah demi langkah:

A B C D E
1 Nama MTK B.Indo B.Ing
2 Budi 85 80 90
3 Ani 92 88 95
4 Cici 78 85 82
5 Dodi 90 92 87

Langkah Membuat Tabel (Detail)

1

Ketik Header (Baris Judul Kolom)

Klik sel A1, ketik Nama, tekan Tab. Sel otomatis pindah ke B1. Lanjut ketik MTK, Tab, dst.

2

Isi Data Siswa Baris 2-5

Klik sel A2, ketik Budi → Tab → 85 → Tab → 80 → Tab → 90 → Enter.

Lanjutkan sampai semua 4 siswa terisi (Ani, Cici, Dodi).

3

Format Header (Bold + Warna)

Blok sel A1 sampai E1. Lalu:

  • Tekan Ctrl+B untuk Bold
  • Klik ikon Fill Color → pilih warna muda
4

Beri Border (Garis Tabel)

Blok seluruh tabel (A1 sampai E5). Klik ikon Borders → pilih All Borders.

5

Sesuaikan Lebar Kolom (AutoFit)

Geser garis antar kolom header sampai lebar cukup, atau double-click garisnya untuk auto-fit.

6

Simpan File

Tekan Ctrl+S → beri nama Tabel_Nilai_Budi.xlsx.

BAGIAN 4

Rumus Dasar Excel

Semua rumus di Excel harus diawali dengan tanda sama dengan (=). Tanpa tanda ini, Excel akan menganggapnya sebagai teks biasa.

1. Operator Aritmatika

Operator Fungsi Contoh Hasil
+ Penjumlahan =5+3 8
- Pengurangan =10-4 6
* Perkalian =6*7 42
/ Pembagian =20/4 5
^ Pangkat =2^3 8

2. Fungsi Dasar (Built-in Functions)

Excel punya fungsi bawaan untuk perhitungan cepat:

SUM

Menjumlahkan semua angka dalam range.

=SUM(B2:D2)
AVERAGE

Menghitung rata-rata dari suatu range.

=AVERAGE(B2:D2)
MAX

Mencari nilai tertinggi dalam range.

=MAX(B2:B5)
MIN

Mencari nilai terendah dalam range.

=MIN(B2:B5)
COUNT

Menghitung banyaknya sel yang berisi angka dalam suatu range.

=COUNT(B2:B5)
BAGIAN 5

Fungsi Logika & Kondisional (IF & COUNTIF)

Excel tidak cuma bisa menghitung angka, tapi juga bisa mengambil keputusan berdasarkan kondisi tertentu. Di Excel, ini bernama fungsi IF.

1. Fungsi IF — Pengambilan Keputusan Sederhana

Fungsi IF memilih satu dari dua nilai berdasarkan kondisi. Kalau kondisi BENAR, pakai nilai pertama. Kalau SALAH, pakai nilai kedua.

Analogi Sehari-hari

"Kalau hujan, saya bawa payung. Kalau tidak hujan, saya bawa topi."
Dalam Excel: =IF(hujan, "payung", "topi")

Sintaks

=IF(kondisi, nilai_jika_benar, nilai_jika_salah)

Operator Perbandingan

Operator Artinya Contoh
= Sama dengan =B2=10
> Lebih besar =B2>10
< Lebih kecil =B2<10
>= Lebih besar atau sama =B2>=10
<= Lebih kecil atau sama =B2<=10
<> Tidak sama dengan =B2<>10

2. Contoh 1: Cek Stok Barang Toko

A B C
1 Barang Stok Status
2 Buku Tulis 25 Aman
3 Pulpen 3 Restock
4 Penghapus 12 Aman
5 Penggaris 7 Restock

Rumus di sel C2

=IF(B2<10, "Restock", "Aman")

Kalau stok < 10 → "Restock". Kalau tidak → "Aman".

Penting: Teks di dalam IF harus diapit tanda kutip dua. Kalau ditulis Restock tanpa kutip, Excel akan error #NAME?.

3. Contoh 2: IF Bersarang (Nested IF) — Kategori Usia

Untuk kondisi lebih dari 2, susun IF bertingkat:

=IF(B2<12, "Anak",
IF(B2<18, "Remaja",
IF(B2<60, "Dewasa", "Lansia")))

Cara Baca Logika Bertingkat

  1. Umur < 12? → Anak. Selesai.
  2. Kalau tidak, umur < 18? → Remaja. Selesai.
  3. Kalau tidak, umur < 60? → Dewasa. Selesai.
  4. Kalau semua tidak → Lansia.

4. Fungsi COUNTIF — Menghitung Sesuai Kriteria

COUNT menghitung semua angka. COUNTIF menghitung yang memenuhi syarat tertentu saja.

COUNT

Hitung semua sel berisi angka.

=COUNT(B2:B5)
COUNTIF

Hitung sel yang memenuhi kriteria.

=COUNTIF(C2:C5, "Restock")

Sintaks COUNTIF

=COUNTIF(range, kriteria)

Range

Area sel. Contoh: C2:C5

Kriteria

Syarat. Contoh: "Restock" atau "<10"

5. Kombinasi IF + COUNTIF — Rekap Absensi

Pola umum: IF untuk status per baris, lalu COUNTIF untuk hitung total.

Langkah 1 — Status per baris (IF)

Di sel C2:

=IF(B2<=TIME(7,0,0), "Tepat Waktu", "Terlambat")

Langkah 2 — Hitung total (COUNTIF)

Di sel C7:

=COUNTIF(C2:C6, "Tepat Waktu")

Intinya: IF untuk mengambil keputusan. COUNTIF untuk menghitung sesuai kriteria. Dua fungsi ini adalah pintu masuk ke analisis data di Excel!

BAGIAN 6

Membuat Grafik (Chart)

Grafik mengubah angka-angka jadi visual yang lebih mudah dipahami. Excel menyediakan Column, Line, Pie, Bar, Area, dan lainnya.

1. Jenis-Jenis Grafik

Column / Bar

Untuk membandingkan nilai antar kategori.

Line

Untuk melihat tren dari waktu ke waktu.

Pie

Untuk proporsi bagian dari keseluruhan (%).

2. Langkah Membuat Grafik

1

Blok data yang ingin digrafikkan

Klik A1 → seret sampai D5. Pastikan sertakan header (baris 1).

2

Klik tab Insert → pilih jenis Chart

Misal Insert → Column Chart → Clustered Column. Cara cepat: Alt+F1.

3

Atur posisi grafik

Drag grafik ke area kosong di sebelah kanan tabel.

4

Tambahkan judul & label

Klik grafik → ikon + → centang Chart Title, Axis Titles, Data Labels, Legend.

Tips memilih grafik:

  • Bandingkan nilai → Column / Bar
  • Lihat perubahan sepanjang waktu → Line
  • Lihat proporsi dari keseluruhan → Pie
  • Tunjukkan korelasi 2 data → Scatter (XY)

Mini Excel — Latihan Rumus Interaktif

Ketik rumus, pilih kolom, lalu seret fill handle untuk auto-copy rumus ke bawah — persis Excel asli!

Cara Pakai (seperti Excel asli)

  1. Klik cell tempat kamu ingin menaruh hasil (misalnya D2)
  2. Klik kotak rumus (ƒx) di atas, lalu ketik nama fungsinya — mis. =SUM(
  3. Sambil kotak rumus masih aktif, klik dan tahan di grid, lalu seret untuk memilih range → referensinya otomatis masuk ke rumus
  4. Ketik ), lalu tekan Enter → hasil muncul! 🎉
  5. Auto-copy rumus: Klik cell yang sudah berisi rumus → cari kotak kecil hijau di pojok kanan-bawah cell → seret ke bawah → rumus otomatis ter-copy! ✨
Mode edit aktif — klik & seret cell di grid untuk memasukkan referensi ke rumus
A1 ƒx
Siap menerima rumus

Mulai Cepat — Klik Rumus

Klik salah satu → rumus akan masuk ke kotak rumus. Lalu seret range di grid → Enter.

1. Menghitung Rata-rata Nilai Siswa dengan AVERAGE

Langkah-Langkah:

  1. Klik sel E2 (kolom Rata-rata, baris Andi)
  2. Ketik rumus =AVERAGE(
  3. Blok range nilai Tugas, UTS, dan UAS milik Andi — dari B2 sampai D2 (nilai 80, 70, 75)
  4. Ketik ) lalu tekan Enter
  5. Hasil muncul di E2 = 75 (dari (80+70+75) ÷ 3)
  6. Copy rumus ke siswa di bawahnya: klik E2 → tarik fill handle (kotak kecil di pojok kanan-bawah) ke bawah sampai E6
// Rumus di sel E2
=AVERAGE(B2:D2)
// Hasil: (80 + 70 + 75) ÷ 3 = 75

Kunci: AVERAGE menjumlahkan semua angka dalam range lalu membaginya dengan jumlah data. Kalau salah satu sel kosong atau berisi teks, tidak dihitung sebagai pembagi.

2. Menghitung Nilai Tertinggi Siswa dengan MAX

Langkah-Langkah:

  1. Klik sel F2 (kolom Max, baris Andi)
  2. Ketik rumus =MAX(
  3. Blok range yang sama: B2:D2
  4. Ketik ) lalu tekan Enter
  5. Hasil muncul di F2 = 80 (nilai tertinggi Andi dari Nilai Tugas)
  6. Tarik fill handle ke bawah untuk copy ke F3:F6
// Rumus di sel F2
=MAX(B2:D2)
// Hasil: 80 (yang terbesar antara 80, 70, 75)

Kapan pakai MAX? Untuk melihat pencapaian terbaik — misalnya nilai ujian tertinggi siswa, penjualan terbesar bulan ini, atau rekor waktu tercepat.

3. Menghitung Nilai Terendah Siswa dengan MIN

Langkah-Langkah:

  1. Klik sel di kolom baru (misalnya G2 kalau F sudah dipakai)
  2. Ketik rumus =MIN(
  3. Blok range B2:D2
  4. Ketik ) lalu tekan Enter
  5. Hasil muncul = 70 (nilai terendah Andi dari UTS)
  6. Tarik fill handle ke bawah untuk siswa lainnya
// Rumus di sel G2
=MIN(B2:D2)
// Hasil: 70 (yang terkecil antara 80, 70, 75)

Kapan pakai MIN? Untuk identifikasi titik lemah — misalnya nilai terendah siswa, produk paling sedikit terjual, atau pengeluaran terkecil.

4. Menghitung Jumlah Data dengan COUNT / COUNTA

Langkah-Langkah:

  1. Pilih sel kosong di bawah tabel, misalnya A8
  2. Ketik =COUNT(B2:B6) → untuk menghitung sel yang berisi angka
  3. Atau =COUNTA(A2:A6) → untuk menghitung sel yang tidak kosong (angka maupun teks)
  4. Hasil: 5 (jumlah siswa yang punya nilai)
// Hitung sel berisi angka (numerik)
=COUNT(B2:B6) → hasil: 5
// Hitung sel tidak kosong (angka atau teks)
=COUNTA(A2:A6) → hasil: 5 (nama siswa)

Bedanya COUNT vs COUNTA: COUNT hanya menghitung angka (kalau sel kosong atau teks, tidak dihitung). COUNTA menghitung apapun yang ada isinya (angka, teks, atau simbol).

5. Menentukan Keterangan Lulus / Tidak Lulus dengan IF

📌 Ketentuan Kelulusan:

Batas skor minimal untuk lulus adalah 75. Jadi:

Rata-rata ≥ 75

→ "Lulus"

Rata-rata < 75

→ "Tidak Lulus"

Langkah-Langkah:

  1. Klik sel di kolom keterangan (misalnya H2)
  2. Ketik rumus IF lengkap seperti di bawah
  3. Tekan Enter → hasil muncul "Lulus" atau "Tidak Lulus"
  4. Tarik fill handle ke bawah untuk semua siswa
// Rumus di sel H2 (kolom Keterangan)
=IF(E2>=75, "Lulus", "Tidak Lulus")
// E2 = kolom Rata-rata
// 75 = batas minimal kelulusan

Penjelasan Logika IF:

  • Excel cek: apakah nilai di E2 ≥ 75?
  • Kalau BENAR → tampilkan "Lulus"
  • Kalau SALAH → tampilkan "Tidak Lulus"

Intinya: Kombinasi AVERAGE (rata-rata) + MAX/MIN (nilai ekstrem) + IF (keputusan otomatis) adalah "triple combo" yang paling sering dipakai di dunia nyata — mulai dari rekap nilai guru, laporan penjualan, sampai dashboard bisnis. Kuasai 3 ini, kamu sudah bisa mengolah 80% data sehari-hari!
