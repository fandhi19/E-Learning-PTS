BAGIAN 1

Pseudocode (Kode Semu)

1. Pengertian Pseudocode

Secara bahasa, Pseudocode berasal dari kata Pseudo (semu/palsu) dan Code (kode).

Pseudocode adalah kode semu / informal yang digunakan manusia untuk menggambarkan alur algoritma (langkah-langkah penyelesaian masalah) sebelum ditulis ke bahasa pemrograman asli.

Analogi Sederhana

Bayangkan Pseudocode seperti Rancangan / Draf Resep Masakan. Sebelum koki memasak di dapur sebenarnya (menggunakan bahasa pemrograman), koki menuliskan dulu langkah-langkah ringkas di kertas dengan bahasa yang mudah dibaca oleh siapa saja.

2. Karakteristik Pseudocode

Agar tidak bingung, kenali ciri khas utama dari pseudocode:

Sederhana & Informal

Tidak memiliki aturan penulisan yang kaku seperti bahasa pemrograman asli.

Mirip Bahasa Manusia

Menggunakan kata-kata yang dekat dengan bahasa sehari-hari (biasanya campuran Indonesia & Inggris).

Satu Baris, Satu Perintah

Setiap langkah ditulis dalam satu baris terpisah.

Menggunakan Indentasi

Menjorok ke dalam untuk menunjukkan tingkatan blok perintah (IF atau perulangan).

3. Istilah Perintah Umum dalam Pseudocode

Ada beberapa istilah kata kunci yang sering digunakan:

Kata Kunci Fungsi Contoh Penggunaan
INPUT / READ Menerima masukan data dari pengguna. input panjang, lebar
PRINT / OUTPUT Menampilkan hasil ke layar. print luas
SET / ← Mengisi/mengubah nilai ke suatu variabel. luas ← panjang * lebar
IF - ELSE Mengambil keputusan berdasarkan kondisi. if nilai >= 75 then ...
WHILE / FOR Melakukan perulangan (pengulangan langkah). while N > 0 do ...

4. Struktur Penulisan Pseudocode

Penulisan pseudocode umumnya dibagi menjadi 3 bagian utama:

1

Judul Algoritma

Menjelaskan nama algoritma yang akan dibuat.

2

Deklarasi / Input-Output

Mendeskripsikan data yang dibutuhkan (input) dan yang dihasilkan (output).

3

Algoritma / Deskripsi

Langkah-langkah pemrosesan logika secara berurutan.

5. Contoh-Contoh Pseudocode

Berikut adalah lima contoh pseudocode beserta deskripsi tingkat tinggi dan hasil keluarannya:

A Menghitung Luas Persegi

Deskripsi Tingkat Tinggi

Algoritma Menghitung Luas Persegi

  • Input: Nilai Panjang Sisi Persegi
  • Output: Luas Persegi tercetak
  1. Baca nilai sisi persegi.
  2. Hitung luas dengan menguadratkan nilai sisinya.
  3. Cetak luas.
// Judul Algoritma
ALGORITMA Menghitung Luas Persegi
// Deklarasi
Input: Nilai Panjang Sisi Persegi
Output: Luas Persegi tercetak
// Algoritma
1. input sisi
2. luas ← sisi * sisi
3. print luas
B Membagi Bilangan (dengan IF-ELSE)

Deskripsi Tingkat Tinggi

Algoritma Membagi Bilangan

  • Input: Pembilang dan Penyebut
  • Output: Hasil Pembagian tercetak
  1. Baca nilai pembilang dan penyebut.
  2. Jika penyebut bernilai 0, cetak "Penyebut tidak boleh nol".
  3. Jika penyebut tidak bernilai nol, lakukan pembagian dan simpan hasilnya.
// Judul Algoritma
ALGORITMA Membagi Bilangan
// Deklarasi
Input: Pembilang dan Penyebut
Output: Hasil Pembagian tercetak
// Algoritma
1. input pembilang, penyebut
2. if penyebut = 0 then
3. print "Penyebut tidak boleh nol"
4. else
5. hasil ← pembilang / penyebut
6. print hasil
C Menghitung Mundur dari N hingga 1 (Perulangan WHILE)

Deskripsi Tingkat Tinggi

Algoritma Menghitung Mundur dari N hingga 1

  • Input: Nilai N
  • Output: Angka hasil hitung mundur dari nilai N sampai 1 tercetak
  1. Baca nilai N.
  2. Selama N > 0, ulangi.
  3. Cetak tulisan N.
  4. Kurangi nilai N dengan 1.
// Judul Algoritma
ALGORITMA Menghitung Mundur dari N hingga 1
// Deklarasi
Input: Nilai N
Output: Angka hitung mundur dari N sampai 1
// Algoritma
1. input N
2. while N > 0 do
3. print N
4. N ← N - 1
D Menghitung Luas Permukaan Kubus

Deskripsi Tingkat Tinggi

Algoritma Menghitung Luas Permukaan Kubus

  • Input: Nilai Panjang Sisi Kubus
  • Output: Luas Permukaan Kubus tercetak
  1. Baca nilai sisi kubus.
  2. Hitung luas (persegi) dari sisi kubus.
  3. Cetak luas_permukaan.
// Judul Algoritma
ALGORITMA Menghitung Luas Permukaan Kubus
// Deklarasi
Input: Nilai Panjang Sisi Kubus
Output: Luas Permukaan Kubus tercetak
// Algoritma
1. input sisi
2. luas_permukaan ← luas(sisi) * 6
3. print luas_permukaan
E Mencari Bilangan Terbesar dari Suatu Himpunan Bilangan

Deskripsi Tingkat Tinggi

Algoritma Mencari Bilangan Terbesar

  • Input: Himpunan bilangan L
  • Output: Bilangan terbesar pada himpunan bilangan L
  1. Jika himpunan bilangan kosong, maka tidak ada bilangan terbesar.
  2. Jika tidak kosong, asumsikan bilangan pertama sebagai bilangan terbesar saat ini.
  3. Untuk setiap bilangan anggota himpunan: bandingkan dengan bilangan terbesar saat ini. Apabila lebih besar, maka bilangan tersebut menjadi bilangan terbesar saat ini.
  4. Apabila langkah 3 telah dilakukan pada seluruh bilangan, bilangan terbesar saat ini akan menjadi bilangan terbesar di himpunan tersebut.
// Judul Algoritma
ALGORITMA Mencari Bilangan Terbesar
// Deklarasi
Input: Himpunan bilangan L
Output: Bilangan terbesar pada himpunan L
// Algoritma
1. if size of (L) = 0 then
2. return null
3. largest ← elemen pertama L
4. for each item in L, do
5. if item > largest, then
6. largest ← item
7. return largest

Catatan: Setelah selesai menyusun suatu algoritma, barulah suatu program dibuat dengan menggunakan bahasa pemrograman tertentu. Ada banyak bahasa yang dapat digunakan, misalnya bahasa C++ yang digunakan pada unit ini dan bahasa Python yang digunakan pada unit analisis data.

BAGIAN 4

Pengenalan Bahasa Pemrograman

Setelah kita membuat rencana/rancangan menggunakan Pseudocode, langkah berikutnya adalah menerjemahkannya ke dalam Bahasa Pemrograman agar komputer bisa menjalankannya.

1. Apa itu Bahasa Pemrograman?

Bahasa Pemrograman adalah kumpulan instruksi/perintah terstruktur yang digunakan manusia untuk berkomunikasi dengan komputer.

Analogi

Komputer seperti orang asing yang tidak paham bahasa Indonesia. Agar komputer paham instruksi kita, kita harus berbicara menggunakan bahasa yang ia mengerti, seperti Bahasa C, Python, atau C++.

Di SMA Kelas X ini, bahasa yang akan dipelajari salah satunya adalah Bahasa C++.

2. Elemen Dasar dalam Pemrograman

A. Variabel

Pengertian: Tempat sementara di memori komputer untuk menyimpan nilai atau data.

Analogi

Variabel seperti Ember/Kotak bertuliskan nama. Jika kotaknya diberi label sisi, maka kita bisa memasukkan angka 5 ke dalam kotak tersebut.

B. Tipe Data

Pengertian: Jenis/tipe dari data yang disimpan di dalam variabel. Komputer perlu tahu tipe datanya agar tidak bingung saat menghitung.

Tipe Data Keterangan Contoh
int Angka bulat 1, 10, -5
float / double Angka pecahan / desimal 3.14, 7.5
char Satu karakter / huruf / simbol 'A', '%'
string Kumpulan kata atau kalimat "Halo Kelas X"

C. Deklarasi Variabel

Pengertian: Proses memperkenalkan/mendaftarkan nama variabel beserta tipe datanya kepada komputer sebelum variabel tersebut digunakan.

Contoh dalam Kode C++:

int umur; // Mendeklarasikan variabel 'umur' dengan tipe data Angka Bulat
float nilai; // Mendeklarasikan variabel 'nilai' dengan tipe data Desimal
BAGIAN 5

Alur Pembuatan Program Secara Umum

Langkah sederhana dari rancangan hingga menjadi program komputer yang siap dijalankan:

1

Analisis Masalah

Memahami apa yang ingin diselesaikan.

2

Buat Pseudocode

Menuliskan alur penyelesaiannya dalam bentuk kode semu.

3

Ketik Kode Program (Coding)

Menuliskan sintaks ke aplikasi IDE seperti Code::Blocks atau VS Code.

4

Kompilasi (Compile)

Komputer mengubah kode tulisan kita menjadi bahasa mesin.

5

Jalankan (Run)

Program menampilkan hasil! 🎉

Intinya: Pseudocode = rancangan di kertas. Program = masakan jadi yang dibuat dari rancangan tersebut.

BAGIAN 6 • B

Bahasa Pemrograman Prosedural

Belajar Pemrograman Seperti Belajar Bahasa

Belajar bahasa pemrograman sama halnya dengan belajar bahasa apa pun — dimulai dengan secara intuitif mengenal dan langsung memakai bahasa tersebut untuk keperluan sehari-hari yang penting sesuai kebutuhan, bukan dari teori bahasa.

Seseorang dengan bahasa ibu bahasa Indonesia, saat belajar bahasa Inggris, akan mulai mengenal bahasa Inggris melalui "membaca" contoh-contoh kalimat sederhana yang sangat diperlukan dalam kehidupan sehari-hari, seperti mulai menyapa "Selamat pagi", "Jam berapa?". Melalui contoh tersebut, ia akan belajar kosakata penting dan pola kalimat. Selanjutnya, baru beranjak ke konsep yang lebih kompleks.

Belajar pemrograman pada hakikatnya sama dengan belajar bahasa natural: seseorang belajar dari "membaca" program terlebih dulu, daripada "menulis" kode program. Proses menulis kode (coding) dapat dimulai setelah kalian membaca contoh-contoh program yang menjadi pola pembangun program kompleks.

Bedanya dengan bahasa natural: teks dalam bahasa pemrograman yang ditulis bukan dilafalkan dan dipahami sebagai teks "statis", melainkan juga dapat dipahami oleh mesin dan dapat dieksekusi (dijalankan).

Empat Elemen Generik Bahasa Pemrograman Prosedural

Terdapat banyak bahasa pemrograman, dan setiap bahasa memiliki paradigma, keunggulan, tantangan masing-masing. Pada unit ini, kalian diperkenalkan pada bahasa pemrograman C++ yang merupakan salah satu bahasa pemrograman prosedural (dan juga mendukung pemrograman berorientasi objek).

1. Variabel

Wadah untuk menyimpan nilai di memori komputer.

2. Ekspresi

Kombinasi nilai, variabel, dan operator untuk menghasilkan nilai baru.

3. Struktur Kontrol Keputusan

Percabangan (if/else) untuk mengambil keputusan berdasarkan kondisi.

4. Struktur Kontrol Perulangan

Looping (for/while) untuk mengulang instruksi beberapa kali.

Penting: Empat elemen ini berlaku di semua bahasa pemrograman prosedural lainnya. Unit ini tidak dibuat hanya agar kalian menguasai pemrograman dengan bahasa C++, tetapi bagaimana kalian dapat menggunakan keempat elemen dasar tersebut dalam membuat suatu program.

BAGIAN 7 • C

Bahasa Pemrograman C++

1. Sejarah Singkat Bahasa C++

Bahasa Pemrograman C++ dikembangkan oleh Bjarne Stroustrup di Bell Labs (AT&T) mulai tahun 1979. Awalnya bahasa ini diberi nama "C with Classes" karena merupakan pengembangan dari bahasa C dengan tambahan fitur class (kelas).

Nama "C++" sendiri baru dipakai pada tahun 1983. Operator ++ dalam bahasa C berarti "increment" (menambah satu), sehingga C++ bisa diartikan sebagai "C yang ditingkatkan". C++ merupakan superset dari bahasa C — hampir semua program C dapat dijalankan sebagai program C++, tetapi tidak sebaliknya.

Sejarah Singkat C++

  • 1979Bjarne Stroustrup mulai mengembangkan "C with Classes".
  • 1983Nama resmi diubah menjadi "C++".
  • 1985Rilis komersial pertama C++ dan buku "The C++ Programming Language".
  • 1998Standar C++ pertama (C++98) disahkan oleh ISO.
  • 2011C++11 — pembaruan besar dengan fitur modern.
  • 2020C++20 dirilis dengan fitur canggih seperti modules dan concepts.

Compiler C++ populer: GCC (g++), Clang, Microsoft Visual C++, dan MinGW.

2. Kelebihan Bahasa C++

Bahasa C++ banyak dipakai untuk membuat sistem operasi, game engine, aplikasi desktop, perangkat lunak tingkat rendah atau "dekat" ke perangkat keras, membuat toolkit pemrograman, hingga aplikasi keuangan dan embedded system.

Singkat & Cepat

Kode yang dihasilkan ringkas dan cepat dieksekusi.

Mendukung OOP

Bisa memakai paradigma berorientasi objek (class & object).

Dekat ke Hardware

Cocok untuk kontrol peralatan, IoT, dan sistem operasi.

Karena fleksibel: C++ adalah salah satu bahasa paling banyak digunakan di dunia industri. Banyak game engine terkenal seperti Unreal Engine dan sebagian besar browser modern ditulis dalam C++.

BAGIAN 8

Membuat Program Pertama dengan Bahasa C++

1. Persiapan Lingkungan Pengembangan

Sebelum mulai membuat program, ada dua hal yang harus kalian persiapkan:

1

Lingkungan Pengembangan

Tempat untuk bekerja — perangkat lunak yang dipakai untuk menulis kode.

2

Proses Membuat Program

Mulai dari mengetikkan kode hingga menghasilkan program yang dapat dieksekusi oleh komputer.

2. Alur Proses Kompilasi Program C++

Berikut adalah alur proses membuat program dengan Bahasa C++:

Source Code main.cpp
Preprocessor #include, #define
Compiler → Object Code
Linker + Library
Executable main.exe
CPU Eksekusi

Penjelasan setiap tahapan:

1. Editor Teks

Tempat kita mengetikkan kode program bahasa C++ (disimpan dengan ekstensi .cpp).

2. Preprocessor

Memproses perintah berawalan # seperti #include <iostream> sebelum kompilasi.

3. Kompilator (Compiler)

Membaca kode C++ dan mengubahnya menjadi kode objek (bahasa mesin / assembly).

4. Assembler

Mengubah bahasa assembly ke dalam kode biner yang dapat dipahami dan dieksekusi komputer.

5. Linker (Penghubung)

Menyatukan kode objek dengan berbagai library menjadi satu berkas executable (.exe di Windows).

3. IDE (Integrated Development Environment)

Pada awalnya, perangkat lunak untuk kompilasi terpisah-pisah. Namun untuk memudahkan, dibuatlah sebuah perangkat lunak terintegrasi yang mencakup semua perangkat lunak di atas. Perangkat lunak tersebut disebut Lingkungan Pengembangan Terpadu (Integrated Development Environment).

Kenapa IDE? Dulu, membuat program C++ sangat rumit (kompilasi manual step-by-step). Sekarang dengan IDE: tulis program → satu kali klik → langsung bisa tampil!
