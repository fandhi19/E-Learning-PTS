Studi Kasus: Kriteria Kelulusan Ujian "Patbhe Test"

Studi kasus sederhana — 1 input, 1 percabangan IF-ELSE

Sistem penilaian sekolah membutuhkan program otomatis untuk menentukan status kelulusan siswa pada mata pelajaran Informatika. Program hanya menerima satu masukan (input), yaitu nilai_ujian siswa.

Aturan Logika 1

JIKA nilai_ujian ≥ 75, maka sistem akan menampilkan pesan "Selamat, Anda Dinyatakan LULUS!" ke layar.

Aturan Logika 2

JIKA TIDAK (yaitu nilai_ujian < 75), sistem akan menampilkan pesan "Maaf, Anda Harus Mengikuti Remedial!"

TP 3

Merancang Pseudocode

Tuliskan rancangan algoritma untuk studi kasus Kriteria Kelulusan "Patbhe Test" menggunakan format pseudocode! Gunakan struktur notasi yang terstruktur (DEKLARASI dan ALGORITMA) serta terapkan aturan indentasi.

Petunjuk: Isi bagian yang kosong (titik-titik) agar pseudocode lengkap dan benar. Perhatikan indentasi (menjorok ke dalam) pada baris di dalam blok IF atau ELSE.

Template Pseudocode
Algoritma CekKelulusan_PatbheTest

DEKLARASI:
// Tuliskan nama variabel yang digunakan di sini:
nilai_ujian : .........................

ALGORITMA:
// 1. Baca / Input data masukan
input .........................................................

// 2. Evaluasi Kondisi Percabangan (Gunakan IF - ELSE)
if .................................................... then
// Tuliskan cetak pesan jika LULUS
print "..................................................."
else
// Tuliskan cetak pesan jika TIDAK LULUS
print "..................................................."
endif

Salin template di atas dan lengkapi bagian yang kosong. Pastikan indentasi benar!
